# Fonts

`Inter.ttf` is the unmodified Inter variable font (`opsz`, `wght`) from
[`google/fonts` at `0b58fb370093f9a9f4ff785d94405710b79de67c`](https://github.com/google/fonts/tree/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl/inter).
SHA-256: `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`.
It is embedded for app chrome, not terminal text.

`JetBrainsMonoNLNerdFontMono-Regular.ttf` is JetBrains Mono NL patched by
Nerd Fonts. It fills in the private-use icon glyphs no system face has; the
terminal itself draws in the system monospace face.

`PaperMono-{Regular,Medium,SemiBold}.ttf` are Paper Mono, unchanged from
[`paper-design/paper-mono` at `e6eaeceaef02e77e3db997711e07a16378de2bd7`](https://github.com/paper-design/paper-mono/tree/e6eaeceaef02e77e3db997711e07a16378de2bd7),
the same faces phux-mobile pins. They set the chrome's machine nouns (hosts,
paths, pane ids, chords), not terminal text. SHA-256:
`130e1a09b64b4f150d34c93a6b7bd52d6c5c3513761d1fbc7be42d68398b8c10` (Regular),
`1609d049b4ec07e358cbd1494afb39886a8415a9a36300222b4d804042803e22` (Medium),
`1b1e6072d9cb533e4305a7076b244aa12127125689c9349fdb977573a35ac65e` (SemiBold).
