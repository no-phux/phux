# Fonts

`Inter.ttf` is the unmodified Inter variable font (`opsz`, `wght`) from
[`google/fonts` at `0b58fb370093f9a9f4ff785d94405710b79de67c`](https://github.com/google/fonts/tree/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl/inter).
SHA-256: `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`.
It is embedded for app chrome, not terminal text.

`JetBrainsMonoNLNerdFontMono-Regular.ttf` is JetBrains Mono NL patched by
Nerd Fonts. It fills in the private-use icon glyphs no system face has; the
terminal itself draws in the system monospace face.

`Inter-OFL.txt` and `JetBrainsMono-OFL.txt` are their licenses.
