**Phux Rune 0.1.0-alpha.9**: a new look, every theme, and the desktop's newest moves.

- **The terminal is a card.** It sits inset with rounded corners on one quiet
  surface, in neutral colours that leave a terminal's own alone.
- **One title bar.** Session and terminal, tabs, updates and link targets share
  the band over the terminal; the status line is gone, so nothing costs a row,
  and the connection is only mentioned when it's in trouble.
- **A sidebar that reads.** A session of one terminal is one row, with what its
  agent is doing beneath the name. Splits dim the panes without the keyboard.
- **Twenty-six themes.** The GPUI desktop's whole set, dark then light, as
  tiles in Settings. **Change Theme** lists them and shows each one live as
  you move; Return keeps it, Escape puts the old one back.
- **Your Ghostty and Omarchy themes.** A Ghostty config on this machine
  becomes the **Ghostty** theme. On Omarchy, the **Omarchy** theme follows the
  current Omarchy theme and is the default until you pick another.
- **Insert Path.** ⌥; (or ⇧⌘I) opens a picker at the cursor that searches the
  pane's folder on the machine it runs on and types the pick as one shell word.
- **Switch Session.** ⇧⌘S finds a session by name, or makes one with the name
  you typed.
- **Typing.** What you type shows as typed, never underlined while the server
  confirms it.
- **Fixed:** choosing System after another theme now really goes back to the
  default colours.
