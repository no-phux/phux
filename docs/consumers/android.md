# Android client

**TL;DR.** The Android client is forthcoming; no release or installation
instructions are documented here.

The Android app links the same `uniffi` surface as iOS, including agent
session records (`WireEvent.AgentRecords`); see
[`ios.md`](./ios.md#agent-session-records).

The attention grade and triage order are the same exported functions
(Kotlin `attentionGrade`, `triageOrder`, and so on), tested against the same
fixture; see [`ios.md`](./ios.md#attention-grade-and-triage-order).
