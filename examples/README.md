# Examples

Small, runnable programs that demonstrate one interface at a time:

- [Drive a terminal from a script](./agents/README.md): enumerate, snapshot,
  run, and wait using the CLI and JSON.
- [A theme plugin](./plugins/theme-pack/README.md): a manifest and one theme,
  with no executable code.

Maintained optional plugins live in [plugins](../plugins/README.md). Test-only
manifests live beside the tests that consume them.
